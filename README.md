# Muhammad Faraz — Portfolio

Personal portfolio of **Muhammad Faraz**, a Full Stack .NET Developer from Karachi, Pakistan. It is an interactive 3D site built with **Next.js**, **React Three Fiber** and **Tailwind CSS**, based on an open-source template (see [Credits](#credits)).

## Highlights

- **Interactive 3D keyboard** — a mechanical keyboard rendered with React Three Fiber; each keycap is a skill.
- **Seasonal themes** — four themes (Winter, Spring, Summer, Autumn) that re-skin the colours and the 3D scene.
- **Project showcases** — dialogs with screenshot carousels, tech stack chips and source code links.
- **Smooth scroll and reveal animations** using [Lenis](https://github.com/darkroomengineering/lenis).
- **Custom cursor** and magnetic buttons.

## Getting Started

**Prerequisites:** Node.js 20+ and npm 10+.

```bash
git clone https://github.com/Faraz778/portfolio.git
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

To build for production:

```bash
npm run build
npm start
```
